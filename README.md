# Smart Quiz System

## Overview
Smart Quiz System is a web-based online examination platform developed using Django, Bootstrap, HTML, CSS, JavaScript, and SQLite.

## Features
- User Registration and Login
- Quiz Management
- Multiple Choice Questions
- Timer-Based Quiz
- Leaderboard
- Performance Dashboard
- Certificate Generation

## Technologies Used
- Python 3.12
- Django 5.x
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript
